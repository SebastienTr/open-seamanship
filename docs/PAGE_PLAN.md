# Page plan

The pages the English edition is built from, by section. File name = slug +
`.md` under `content/en/<section>/`; the page is published at
`<section>/<slug>.html`. Link between pages with relative links, for example
`[Engine overheating](../fix-it/engine-overheating.html)`. Library documents
are at `../library/<source-id>.html`.

Kinds: C = card, G = guide, E = explainer, H = history. `!` = `safety: critical`.
