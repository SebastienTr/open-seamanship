When a word or a number must get through on a bad radio link, spell it out
with these code words. They are the same in every language and every service.
The table follows the International Code of Signals
([Pub. 102, ch. 1, section 10](../library/nga-pub102.html)).

| --- | --- | --- | --- |

| E | Echo | **ECK** oh | • |

Stress the syllables in bold. Note the spellings "Alfa" and "Juliett". "Alfa"
avoids "ph", which some languages do not say as "f"; "Juliett" stops French
speakers from dropping the final "t"
([NATO phonetic alphabet, wikipedia-en](../library/wikipedia-en.html)).

The distress signal SOS in Morse is ••• ––– ••• ([Pub. 102, ch. 4,
section 1](../library/nga-pub102.html)). See
[Distress signals](../emergency/distress-signals.html).

## Figures

The International Code gives each figure a two-part code word. Every syllable
gets equal stress ([Pub. 102, p. 18](../library/nga-pub102.html)).

| Figure | Code word | Say it like | Short form |
| --- | --- | --- | --- |
| 0 | Nadazero | nah-dah-zay-roh | zero |
| 1 | Unaone | oo-nah-wun | wun |
| 2 | Bissotwo | bees-soh-too | too |
| 3 | Terrathree | tay-rah-tree | tree |
| 4 | Kartefour | kar-tay-fower | fower |
| 5 | Pantafive | pan-tah-five | fife |
| 6 | Soxisix | sok-see-six | six |
| 7 | Setteseven | say-tay-seven | seven |
| 8 | Oktoeight | ok-toh-ait | ait |
| 9 | Novenine | no-vay-niner | niner |
| . (decimal point) | Decimal | day-see-mal | decimal |
| . (full stop) | Stop | stop | stop |

The second half of each code word is the word used in aviation
([Pub. 102, p. 18](../library/nga-pub102.html)). Aviation and NATO say 3, 4, 5
and 9 as "tree", "fower", "fife" and "niner" so they are not misheard
([NATO phonetic alphabet, wikipedia-en](../library/wikipedia-en.html)). On the
radio, say numbers digit by digit: 156.8 is "wun fife six decimal ait"; a
course of 045° is "zero fower fife degrees".

Positions are easiest to hear as latitude and longitude, digit by digit, or as
a bearing and distance from a charted point. See
[Mayday distress call](../emergency/mayday-distress-call.html).

## Procedure words

Spoken signals from the International Code ([Pub. 102, pp. 19-20](../library/nga-pub102.html)):

| Say | Meaning |
| --- | --- |
| Interco | International Code groups follow |
| Stop | Full stop |
| Decimal | Decimal point |
| Correction | Cancel my last word or group; the correct one follows |
| (letters) C, "Charlie" | Yes, affirmative |
| NO (say "no") | No, negative |
| RQ | The previous group is a question |
| R | Received |
| RPT | I repeat; or: repeat what you sent |
| AA / AB / BN | (after RPT) all after... / all before... / all between... and... |
| WA / WB | (after RPT) word after... / word before... |
| OK | That is correct |
| AR | End of transmission |
| AS | Wait |
| DE | From... (before your name or call sign) |
| K | Go ahead; I wish to communicate with you |
| CQ | Call to all stations |

Ordinary VHF procedure (calling, "over", "out", Mayday, Pan-Pan, Sécurité) is
in [VHF radio procedure](../run-the-boat/vhf-radio-procedure.html).
